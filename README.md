## 成果物の構成

`poc/dist/` の中身一式を、そのままリポジトリに置いて Pages で公開します。

| パス | 内容 |
|---|---|
| `index.html` / `assets/` | PoC ページ本体（JS/CSS/ランタイム） |
| `model/jvnv-F1-jp-int8.aivmx` | 音響モデル（JVNV F1 / JP-Extra、static int8 量子化、75,657,068 bytes） |
| `ort/` | ONNX Runtime の WASM バイナリ |

- DeBERTa（韻律推定、約241MB）と日本語辞書（約6.7MB）は、このサイトには置かず、ページを開いたときに Hugging Face から直接取得します（sbv2-web の設計どおり。CORS 許可は実測済み）。
- 初回ダウンロード総量は **約337MB** です（このサイトから約90MB＋Hugging Faceから約247MB）。**Wi-Fi 環境で開いてください。** 2回目以降はブラウザにキャッシュされ、ダウンロードは省略されます。
- 全ファイルが GitHub Pages の制限（1ファイル100MB未満・サイト1GB以内）に収まっています（最大ファイルは音響モデルの約76MB、サイト合計約161MB）。

## iPhone での確認チェックリスト

Pages の URL を iPhone 18 Pro の Safari で開いて、次を確認してください。

1. **ページが開けるか**
   - タイトル「Style-BERT-VITS2 ブラウザTTS PoC」が表示されるか
2. **読み込みが完了するか**（一番大事な確認です）
   - 「モデルを読み込む」の「読み込み開始」ボタンを押す
   - 画面の4段階（音響モデル取得 → DeBERTa 取得 → 辞書取得 → セッション生成）が順に ✅ になり、「準備完了」になるか
   - **途中でタブが落ちた場合**（ページが真っ白になる／再読み込みされる／Safari が終了する）は、それ自体が重要な結果です。**どの段階の表示のときに落ちたか**を教えてください
   - エラー表示が出た場合は、その**文面をそのまま**教えてください
3. **短文の合成ができるか**
   - 既定文「こんにちは、今日はいい天気ですね。」のまま「生成する」を押す
   - 音声プレイヤーが出て、声が再生できるか
   - 画面に表示される**生成時間（秒）**を教えてください
4. **感情スタイルを変えて生成できるか**
   - スタイルを「Happy（喜び）」など別のに変えて、もう一度「生成する」
   - 生成できればOKです。声の雰囲気が変わったかどうかも、感想でかまいません

## 結果の報告の仕方

画面に出た内容を、そのまま言葉で伝えてもらえれば大丈夫です。

- 「準備完了まで行った。生成時間は ○ 秒だった」
- 「DeBERTa 取得の途中でタブが落ちた」
- 「エラーに『○○』と出た」

スクリーンショットがあると、なお確実です。

## 注意

- 合成はすべて iPhone のブラウザ内で実行され、入力テキストは外部に送信されません（モデルファイルのダウンロードを除く）。
- 実行方式は既定の「WASM」のままにしてください。「WebGPU」は実験的な選択肢です（うまく動かなくても問題ありません）。
